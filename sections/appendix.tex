\section{Measurement and analysis protocol}
\label{app:measurement}

\paragraph{Completeness and denominators.}
For a prespecified strict-preference cohort of $N$ pairs, let $c_i=1$ when both
artifacts have all $R$ valid complete scores. Let
$m=\sum_i c_i$ and $k=\sum_{i:c_i=1}z_i$, with $z_i$ from
Equation~\ref{eq:measurement}. Report completed-pair accuracy $k/m$ when $m>0$,
coverage $m/N$, and the missing-outcome interval
\begin{equation}
 \left[\frac{k}{N},\frac{k+N-m}{N}\right].
 \label{eq:missing}
\end{equation}
This interval bounds full-cohort agreement under arbitrary missing outcomes; it
is not a statistical confidence interval. A missing repeat is not silently
replaced by the median of surviving calls. Execution completeness includes
selected routes and tools, not just the availability of a final score.
A valid observation that an artifact fails a quality check is distinct from a
tool execution error.

\paragraph{Randomness and repeated use.}
Freeze $R\geq3$, score precision, tie handling, outcome-blind retry policy, and
artifact reuse rules before evaluation. Repeated measurements of the same
artifact are not independent task observations. Paired uncertainty estimates
should resample original input groups, preserving their artifacts and comparisons;
the planned interval level is 95\%. Report the number of independent search
seeds separately from scoring repeats. Repeating calls on the same Val cohort
can assess execution stability, but does not create an independent test set.

\paragraph{Selection boundaries.}
Retain the identities and outcomes of all attempted candidates, including
unsuccessful and incomplete attempts, for the authorized internal analysis.
Previously measured identical programs are not new independent candidates.
Only aggregate sealed-development measurements inform search.
The validation shortlist and its order are fixed from training evidence before
Val access; all shortlisted outcomes are reported. An interrupted search does
not initiate additional terminal assessment. The final test program and any
choice among a multi-candidate shortlist must be prespecified without test-driven
selection.

For each included domain, document source permissions, original-input grouping,
artifact generators, annotation provenance, human agreement, and the availability
of task references. Public benchmark examples must not be presented as private
newly collected annotations, and benchmark-specific labels must remain outside
the deployed scorer's input. Best-of-$N$ requires a fixed multi-artifact pool and
appropriate human assessment beyond any pair-only corpus.
